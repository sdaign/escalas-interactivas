# Laboratorio de escalas

Web estática educativa con cinco retos interactivos sobre escalas de dibujo técnico, basada en la presentación «ESCALAS».

## Publicación en GitHub Pages

1. Crea un repositorio público en GitHub, por ejemplo `escalas-interactivas`.
2. Sube `index.html` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guarda.
5. Abre la dirección que te indique GitHub Pages (normalmente `https://TU-USUARIO.github.io/escalas-interactivas/`).

No requiere instalación, bibliotecas externas, servidor ni cuentas para el alumnado. Abre `index.html` en un navegador para probarlo localmente.

## Evaluación

Cada ejercicio comprueba todos sus campos y, en los ejercicios 2 y 4, que el dibujo sea un rectángulo sólido de las dimensiones esperadas, independientemente de su posición y orientación. Al comprobar se muestra la corrección y una explicación paso a paso. El progreso y las respuestas no se envían ni almacenan.

**Nota:** La cuadrícula virtual representa un papel cuadriculado con cuadrados de 1 cm de lado a efectos matemáticos; el tamaño físico en pantalla depende del dispositivo y del zoom. Los esquemas de objetos reales no están dibujados a escala.
